# Ryleigh Shikhanova — Portfolio

Static portfolio website. No build system or dependencies required.

## Run locally

Open `index.html` directly, or from this directory run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a repository (for example `portfolio` or `ryleigh-shikhanova.github.io`).
2. Add these files at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Deploy from the `main` branch/root directory.

If the repository is named `ryleigh-shikhanova.github.io`, it can be served from the corresponding GitHub Pages user site.
